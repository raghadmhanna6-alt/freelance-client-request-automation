# 04 — AI Design

## 1. AI in the Project
The current implementation focuses on deadline reminders using Google Sheets, Zapier, Formatter, Delay, and Gmail.

## 2. Current AI Status
An AI-powered client request classification feature has not yet been implemented in the current workflow.

## 3. Potential AI Enhancement
An AI tool could analyze incoming freelance client requests and extract useful information, such as:
- Client name
- Requested service
- Project description
- Requested deadline
- Missing information that needs clarification

## 4. Human Review
Before accepting a request or making commitments to a client, the freelancer should review the extracted information and confirm that it is accurate.

## 5. Responsible AI Use
- Do not invent missing client information.
- Flag unclear or incomplete requests.
- Avoid sharing unnecessary personal or confidential information.
- Require human review before important decisions.

## 6. Future Development
A future version could integrate an AI step into Zapier to classify client requests and prepare structured information for review. This feature is a proposal and is not part of the current implemented workflow.
