# 01 — Business Analysis

## Project Name
Freelance Client Request Automation

## 1. Problem Statement
Freelancers often receive project requests from different clients through email or online forms. Managing these requests manually can take time, cause delays, and lead to missed information or deadlines.

## 2. Target Users
The primary users are freelancers who need a simple way to organize client requests and follow up on their projects.

## 3. Proposed Solution
The proposed solution is an automation workflow using Google Sheets and Zapier to organize project information and send email reminders before project deadlines.

## 4. Business Goals
- Reduce manual follow-up work.
- Organize project information in one place.
- Reduce the risk of missing project deadlines.
- Improve time management.

## 5. Tools
- Google Sheets: Stores project information.
- Zapier: Connects the workflow steps and automates actions.
- Formatter by Zapier: Calculates the reminder time.
- Delay by Zapier: Waits until the scheduled reminder time.
- Gmail: Sends the reminder email.

## 6. Expected Benefits
The workflow is expected to help freelancers track project deadlines, reduce repetitive manual work, and receive timely email reminders.

## 7. Project Scope
This implementation focuses on recording project details in Google Sheets and sending an automated email reminder 24 hours before a project deadline.

## 8. Limitations
The current workflow is a basic prototype. It does not yet automate the complete process of receiving, classifying, and approving new client requests. The reminder schedule and timezone must be tested before relying on it for real deadlines.
